# Glossary

| Term | Meaning in this repo |
|---|---|
| **MQL / SAL / SQL** | Marketing-qualified lead → SDR-accepted lead → sales-qualified lead (meeting held + qualification standard met) |
| **Grade (e.g. A2)** | Fit letter (A–D) + intent number (1–4) from the two-axis score |
| **R1–R7** | The ordered routing rules: disqualify, open-opp owner, account owner, partner manager, nurture, SDR pod, ops review |
| **Pod** | SDR group defined by segment + region |
| **Coverage** | Open pipeline closing in the quarter ÷ remaining quota |
| **Forecast accuracy** | 1 − \|commit − actual\| ÷ actual, at week 4, 8 or 12 |
| **Forecast bias** | (commit − actual) ÷ actual; positive = over-call, negative = sandbag |
| **Forecast categories** | Pipeline / Best Case / Commit / Closed / Omitted |
| **EB** | Economic buyer: the persona who can sign |
| **Technical validation** | POC, sandbox or data test; stage 3 in the example config |
| **Security review** | Vendor-risk review; gated in stage 4 in the example config |
| **GRR / NRR** | Gross / net revenue retention |
| **Health band** | Healthy / Watch / At Risk renewal score |
| **HITL** | Human in the loop: a person accepts, edits or rejects AI output before it applies |
| **PII guard** | Allow-list plus redaction applied before any model call |
| **Eval set** | Fixed test cases an AI workflow must pass in CI |
| **Semantic layer** | Typed SQL views every report reads from |
| **L2A** | Lead-to-account matching |
| **PQL** | Product-qualified lead (product-usage signal) |
| **FY27-Q1** | Example fiscal label. With `fiscal.year_start_month: 10`, Oct–Dec 2026 |
| **🟦 / 🟩 / 🟪** | GTM Engineer / Strategy & Ops / both |
