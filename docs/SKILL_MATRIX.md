# GTM Engineering, RevOps, & SalesDev Skill Matrix

| Discipline | Core Responsibilities | Key Tech Stack | Critical Competencies |
| :--- | :--- | :--- | :--- |
| **GTM Engineering** | Custom API webhooks, AI agent workflows, dbt data modeling, reverse ETL | Python, Node.js, dbt, Snowflake/BigQuery, LangChain, Census/Hightouch | API integrations, async event processing, LLM orchestration, data warehousing |
| **Revenue Operations** | Tech stack administration, attribution, pipeline forecasting, compensation planning | HubSpot, Salesforce, Gong, Clari, LeanData | Process design, revenue waterfall reporting, SQL, system architecture |
| **Sales & Business Dev** | Outbound prospecting, lead qualification, multi-channel cadences, discovery calls | Apollo.io, ZoomInfo, Outreach, Salesloft, LinkedIn Sales Navigator | Cold outreach, objection handling, account mapping, deal qualification (MEDDPICC) |

## Role Evolution Spectrum
* **Traditional SalesOps:** Manual CSV exports, basic CRM field creation, static reporting.
* **Modern RevOps:** Unified GTM data engines, automated lead-to-account matching, dbt attribution models.
* **GTM Engineering:** Building autonomous AI agents for prospecting, self-healing webhook infrastructures, programmatic outbound engines.
