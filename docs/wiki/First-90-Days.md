# First 90 Days

Full plan: [FIRST_90_DAYS.md](https://github.com/peytonbackus-spec/sardine-gtm-revops-toolkit/blob/main/FIRST_90_DAYS.md).

| Window | Focus | Outputs |
|---|---|---|
| **Days 1–30** | Learn the machine, fix what's bleeding | Stakeholder 1:1s; stack scorecard; data-quality baseline; agreed definitions; speed-to-lead quick win |
| **Days 31–60** | Build the shared foundation | Semantic layer + dashboards; consumption fields on every Account; scoring calibrated on closed-won; stack decision memo |
| **Days 61–90** | Automate and hand over | Overage → expansion opp; shelfware → CSM task; AI workflows behind human review; weekly forecast hygiene |

**Measures:** speed-to-lead, data-quality pass rate, Accounts with consumption fields populated, overage-sourced expansion pipeline, and manual hours removed per week.
