# Glossary

General terms: [docs/overview/glossary.md](https://github.com/peytonbackus-spec/sardine-gtm-revops-toolkit/blob/main/docs/overview/glossary.md). Sardine-specific:

| Term | Meaning |
|---|---|
| **Minimum commit** | The monthly amount a customer commits to; usage draws it down |
| **Overage** | Usage billed above the commit in a month |
| **Utilization** | Usage ÷ commit, trailing 3 months |
| **Shelfware** | A contract running well under commit after the ramp window |
| **Ramp window** | First months live, excused from shelfware alerts (config: `consumption.ramp_months`) |
| **KYC / KYB** | Know your customer / know your business: identity and business verification at onboarding |
| **AML / BSA** | Anti-money laundering / Bank Secrecy Act compliance |
| **SAR** | Suspicious Activity Report |
| **TPRM / MRM** | Third-party risk management / model risk management: bank review gates |
| **Sponsor bank / BaaS** | A bank that provides accounts and rails to fintech programs |
| **ATO** | Account takeover |
| **Sonar** | Sardine's data consortium |
| **FY26-Q4** | Oct–Dec 2026 under the assumed calendar fiscal year |
